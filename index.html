GitHub 雲端儲存設定
設定完成後，每次新增或修改記錄都會自動存到您的 GitHub repository， 不管用哪台裝置開啟都能看到完整資料，更新網頁也不會遺失資料。
GitHub 連線設定
💡 如何取得 Personal Access Token：
1. 開啟 github.com/settings/tokens
2. 點「Generate new token (classic)」
3. 勾選 repo 權限
4. 複製產生的 token（只顯示一次）

注意事項：
• Token 儲存在瀏覽器 localStorage，不會上傳到任何伺服器
• 上傳的 data.json 會存在您的 repository 中，請勿公開 repository
• 建議將 repository 設為 Private（私有）
